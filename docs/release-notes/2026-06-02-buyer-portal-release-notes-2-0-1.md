**B2B Buyer Portal** plugin `v2.0.1` (2026-06-02) covers Organization Account and Contracts Management. This version adds Accounting Fields and removes Custom Fields from budgets, buying policies, and address locations.

## Upgrade notes

- The navigation menu includes an Accounting Fields submenu. Confirm the new entry is available for the contracts you manage.
- Budget allocation no longer offers Custom Fields options. Selectors use Accounting Fields instead.
- Buying policies no longer offer Custom Fields criteria. Criteria use Accounting Fields instead.
- Address locations now use Accounting Fields instead of Custom Fields. Confirm existing locations still resolve after the upgrade.
- The Locations label in the Addresses settings drawer has changed.
- Legacy Custom Fields are no longer available.

---

## Organization Account

### Added

- Budget allocation uses Accounting Fields in its selector. The previous Custom Fields options are no longer available.
- Buying policies use Accounting Fields as criteria. The previous Custom Fields criteria are no longer available.

---

## Contracts Management

### Added

- The navigation menu includes an Accounting Fields submenu.
- Accounting fields can be created, edited, and deleted in drawers.
- An alert appears when there are no accounting fields.
- Accounting Fields has its own page, including an empty state when there are no fields.
- Accounting field values can be created, edited, deleted, and removed from an organizational unit.
- Accounting fields can be listed, opened, created, updated, and removed.
- Address locations now use Accounting Fields instead of Custom Fields.
- The Locations label in the Addresses settings drawer has been updated.

---

## General

### Added

- Legacy Custom Fields are no longer available.
