To make it easier for partners to integrate payment providers into VTEX, we have published an updated [Payments Integration Guide](https://developers.vtex.com/docs/guides/integrating-a-new-payment-provider-on-vtex). The new guide details how our [Payment Provider Protocol](https://developers.vtex.com/docs/guides/payments-integration-payment-provider-protocol) works and everything you need to know to perform an integration such as:

- [PCI - DSS Compliance](https://developers.vtex.com/docs/guides/payments-integration-pci-dss-compliance) certification
- [Payment methods](https://developers.vtex.com/docs/guides/payments-integration-payment-methods) and [purchase flows](https://developers.vtex.com/docs/guides/payments-integration-purchase-flows)
- API endpoints needed to [implement a payment provider](https://developers.vtex.com/docs/guides/payments-integration-implementing-a-payment-provider)
- Payment provider [homologation](https://developers.vtex.com/docs/guides/payments-integration-payment-provider-homologation) process
