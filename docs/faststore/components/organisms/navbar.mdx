The `Navbar` represents the page header and groups some features like: `Search`, `Regionalization`, `SignIn`, `CartSidebar`. This component is part of the [Navigation](https://developers.vtex.com/docs/guides/faststore/feature-navigation) feature.

Uses `NavbarHeader`, `NavbarRow` and `NavbarButtons` as compound components.

The [NavbarLinks](https://developers.vtex.com/docs/guides/faststore/molecules-navbar-links), [NavbarSlider](https://developers.vtex.com/docs/guides/faststore/organisms-navbar-slider), and [SearchInput](https://developers.vtex.com/docs/guides/faststore/organisms-search-input) components are used as child components.

## Usage

### Import the component

```tsx
import { Navbar, NavbarHeader, NavbarRow, NavbarButtons } from '@faststore/ui'
```

### Hooks used in the example

The **Code** tab of the example uses the following FastStore hooks, both imported from `@faststore/ui`:

- `useScrollDirection`: detects the scroll direction (up or down) so the `Navbar` can hide or show on scroll.
- `useUI`: gives access to the global UI state, such as opening the navigation menu (`openNavbar`) and checking whether it is displayed (`navbar`). It requires the component to be wrapped by `UIProvider`.

For more information, see [FastStore hooks](https://developers.vtex.com/docs/guides/faststore/developer-tools-hooks-overview).

### Import styles

To apply styles, include the following in your stylesheet:

```scss
@import '@faststore/ui/src/components/organisms/Navbar/styles.scss';
```

For details, see [Importing FastStore UI component styles](https://developers.vtex.com/docs/guides/faststore/using-themes-importing-ui-components-styles).
