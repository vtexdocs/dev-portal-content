# Documentation Pipeline: Request to Review

## From Request to Pipeline

A documentation drafting run begins when a request enters the system. Each request carries metadata that describes what content is needed, which repository should host it, and where it belongs in the documentation structure. The system captures this information and passes it to the drafting stage.

## Drafting and Iteration

The draft agent processes the request and creates initial content according to specifications. This draft goes through multiple iterations if needed, with each round refining clarity and structure. The agent follows templates and guidelines to ensure consistency with existing documentation standards.

## Review and Delivery

Once drafting completes, the content moves to review. Reviewers assess whether the draft meets requirements and quality standards. After approval, the pipeline delivers the file to the target repository at its designated path, making it available to readers.
